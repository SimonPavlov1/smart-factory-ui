# Руководство пользователя

## Вход

Откройте frontend и войдите под своей учётной записью. Доступные разделы и действия зависят от ролей пользователя.

## Создание производственной заявки

1. Откройте «Заявки».
2. Нажмите «Создать заявку».
3. Укажите заказчика, плановую дату и изделия.
4. Проверьте количество по каждой позиции.
5. Сохраните заявку.

Дата поставки не может находиться в прошлом. После создания система проверит BOM и склад. При наличии части компонентов доступная часть может быть зарезервирована и выдана, а закупка создаётся только на дефицит.

## Работа с задачами

Раздел «Все задачи» поддерживает режимы «День», «Неделя», «Месяц» и «По заказам». Навигация выполняется стрелками, кнопкой «Сегодня» или выбором даты.

Чтобы выполнить задачу:

1. откройте карточку;
2. нажмите «Взять в работу», если задача свободна;
3. заполните обязательные поля этапа;
4. передайте обработанную часть дальше;
5. повторите для оставшихся изделий.

Не обязательно ждать завершения всей партии: тестирование, упаковка и склад принимают частичную обработку.

## Создание ручной задачи

1. Откройте «Все задачи».
2. Нажмите «+ Задача» рядом с навигацией календаря.
3. Укажите отдел, исполнителя, срок и приоритет.
4. При необходимости выберите заказ, изделие, наблюдателей и задачу-предшественника.
5. Нажмите «Создать задачу».

## Сборка

Сборщик работает с общим пулом устройств:

- берёт свободные заводские номера;
- отмечает собранные экземпляры;
- может освободить ошибочно взятый номер;
- передаёт готовую часть на тестирование без ожидания всей партии.

Взятие устройства не переключает интерфейс автоматически на другой фильтр.

## Тестирование

Несколько тестировщиков могут разделить одну задачу:

1. закрепите свободные устройства за собой;
2. откройте устройство;
3. пройдите каждый пункт чек-листа;
4. сохраните результат;
5. передайте проверенную часть дальше.

Нельзя сохранять результат по устройству, закреплённому за другим тестировщиком.

## Ремонт

В заявке на ремонт устройства разделены по заводским номерам. Для каждого отображаются причины дефекта из чек-листа.

После ремонта:

1. укажите, что сделано с каждым устройством;
2. при необходимости запросите дополнительные компоненты;
3. передайте устройство на повторное тестирование.

Из ремонта устройство не передаётся прямо на упаковку.

## Упаковка и готовая продукция

Упаковщик выбирает конкретные прошедшие тест устройства и может передавать их партиями. Кладовщик готовой продукции принимает только упакованные экземпляры.

Повторное оприходование уже принятого заводского номера блокируется.

## Склад комплектующих

В карточке компонента доступны:

- текущий и зарезервированный остаток;
- приход и списание;
- ручная корректировка;
- история движения.

История загружается частями. Полный журнал доступен в отдельном табличном представлении.

## Отмена заявки

Отмену запускает руководитель. Если по заказу уже были резервы, закупки или выдача материалов, сначала необходимо закрыть сформированные системой обязательства. Только после этого заявка получает окончательный статус отмены.
