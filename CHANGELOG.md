# Changelog

## 2.0.1 — 2026-07-27

### Добавлено

- в паспорте изделия можно задать начальный заводской номер; генератор продолжает последовательность без повторного использования уже выданных номеров.

## 2.0.0 — 2026-07-27

Основной релиз CRM/MES «Проекты».

### Добавлено

- календарь задач: день, неделя, месяц и группировка по заказам;
- ручные задачи, зависимости, наблюдатели и приоритеты;
- общий пул устройств для сборщиков и тестировщиков;
- работа по заводским и децимальным номерам;
- чек-лист отдельно для каждого устройства;
- предсборочное и повторное тестирование;
- ремонт с результатом по каждому устройству;
- частичная упаковка и оприходование;
- история движений компонентов и готовой продукции;
- безопасная отмена производственной заявки;
- тёмная тема и единая CRM-дизайн-система;
- Docker Compose для запуска в локальной сети;
- полная пользовательская и техническая документация.

### Исправлено

- зависание накопительных задач разных изделий;
- повторное оприходование одной партии;
- потеря заводских номеров между задачами;
- параллельная работа нескольких сборщиков и тестировщиков;
- маршрутизация после ремонта;
- адаптивность календаря, канбана и карточек.
